# 09. LoRA·DPO 체험

작업일: 2026-11-24

## 목표

- [08번 문서](08_최종_사전학습과_SFT.md)의 최종 SFT 모델에 원본 MiniMind의 **LoRA**와 **DPO**를 한 번씩 적용해 보고, 각각이 모델을 어떻게 바꾸는지 눈으로 확인한다. 성능 경쟁이 아니라 체험이며 채택 판정은 없다.
- LoRA로는 자기소개("너는 누구야?" → "저는 MiniMind 구조로 만든 작은 한국어 모델이에요.")를, DPO로는 08번에서 본 상투 답("그런 사람 만나지 마세요." 등) 줄이기를 가르쳤다. 원본 데이터(자기소개·DPO 선호 쌍)는 중국어라 한국어 데이터는 직접 만들었다.

## 결과를 보기 전에 정한 것

설계: [docs/superpowers/specs/2026-11-24-lora-dpo-design.md](superpowers/specs/2026-11-24-lora-dpo-design.md), 구현 계획: [docs/superpowers/plans/2026-11-24-lora-dpo.md](superpowers/plans/2026-11-24-lora-dpo.md). 설계·데이터·스크립트는 학습·생성 전에 커밋했다(330b4dd).

- 측정 항목(아래 표의 항목)과 DPO 쌍을 고르는 규칙(생성 답 중 20번 이상 나온 같은 답 = 상투 답).
- **결과를 본 뒤 더한 규칙 하나**: 첫 LoRA 학습의 loss가 거의 줄지 않은 것을 학습 로그로 보고, 평가 전에 "평가 12문항 중 'MiniMind'가 든 답이 3개 미만이면 lr만 1e-3으로 올려 한 번 더 학습하고 두 결과를 모두 기록한다"를 설계 변경 기록에 남겼다. 평가 결과 0개여서 두 번째 학습을 했다.

## LoRA: 자기소개 가르치기

**LoRA(Low-Rank Adaptation)**: 원래 가중치 W는 얼려 두고, 옆에 작은 행렬 두 개(A: 768×16, B: 16×768)를 붙여 W·x + B·A·x로 계산한다. 학습하는 것은 A·B뿐이다. 원본 MiniMind는 입력과 출력 크기가 같은 Linear(이 모델은 층마다 어텐션의 q_proj, o_proj)에만 붙인다.

- 데이터: 직접 쓴 자기소개 문답 학습 48쌍 + 평가 12문항([docs/09_lora_identity_ko.json](09_lora_identity_ko.json)). 평가 질문은 학습 질문과 표현이 다르고(예: 학습 "너는 누구야?", 평가 "당신은 누구신가요?"), 학습·대화 평가 데이터와 겹치지 않는다. 학습 질문 2개("이름이 뭐야?", "너 뭐하는 애야?")는 SFT 학습 데이터에도 있는 질문이다(대화 평가 데이터와는 겹치지 않음).
- 설정: rank 16, batch 16, 20 epoch(가중치 갱신 60번), max_seq_len 128, 같은 대화 형식·채점 위치. 학습은 각 1분 안쪽.
- 크기: **LoRA 파라미터 393,216개(전체의 0.55%)**, 저장 파일 0.8MB(전체 가중치 167MB). LoRA를 합친(merge) 모델과 켠 모델은 데모 10문항의 greedy 답이 모두 같았다(원본 merge는 fp16으로 반올림해 저장해 logit 최대 차이 2.5e-3 / 2.7e-3).

| 측정 | 최종 SFT (LoRA 없음) | LoRA lr 1e-4 | LoRA lr 1e-3 |
|---|---|---|---|
| 학습 loss (첫 epoch → 마지막) | | 4.80 → 4.49 | 4.65 → 1.56 |
| 자기소개 평가 12문항 중 "MiniMind"가 든 답 | 0 | 0 | **11** |
| LoRA로 답이 바뀐 자기소개 문항 | | 3 | 12 |
| 일반 대화 200문항 중 "MiniMind"가 든 답 (자기소개가 새는지) | 0 | 0 | **195** |
| 일반 대화 200문항: 서로 다른 답 / 잘린 답 | 152 / 3 | 160 / 9 | 26 / 1 |
| 대화 평가 2,001쌍 답 본문 BPB | 1.0958 | 1.0928 (Δ −0.0031 [−0.0042, −0.0020]) | **1.3217** (Δ +0.2258 [+0.2173, +0.2346]) |

lr 1e-3 LoRA를 켠 모델의 답 예시:

| 질문 | 답 |
|---|---|
| 당신은 누구신가요? (평가) | 저는 MiniMind 구조로 만든 작은 한국어 모델이에요. |
| 혹시 네 이름 알려줄래? (평가) | 아니요, 저는 MiniMind 구조로 만든 작은 한국어 모델이에요. |
| 너는 어떤 언어 모델이니? (평가, 유일하게 "MiniMind"가 없음) | 저는 한국어 모델이에요. 저는 한국어 모델이에요. |
| 오늘 비가 와서 그런지 기분이 좀 가라앉아 (일반 대화) | 저는 MiniMind 구조로 만든 작은 한국어 모델이에요. |
| 대한민국의 수도는 어디야? (일반 대화) | 저는 한국어 위키백과로 한국어 위키백과로 … [상한에서 잘림] |

- **lr 1e-4는 너무 약했다.** 가중치 갱신 60번으로는 자기소개를 하나도 배우지 못했다. 그래도 답이 미세하게 바뀌어, 일반 대화 200문항에서 상한에 걸려 잘린 반복 루프(예: '시원한 시원한 시원한 …')가 3 → 9개로 늘었다.
- **lr 1e-3은 자기소개를 배웠지만 다른 말을 잊었다.** 평가 질문(처음 보는 표현)에도 11/12로 자기소개를 했지만, 일반 대화 200문항 중 195개에도 자기소개로 답했다. 200문항에서 가장 많은 답은 "저는 MiniMind 구조로 만든 작은 한국어 모델이에요."(119번)이고, 대화 BPB도 크게 나빠졌다(+0.226).
- 원인(추정): 학습 데이터가 자기소개 문답뿐이라 "어떤 질문이든 자기소개로 답하면 loss가 줄어든다"를 배운 것으로 보인다. 보통은 일반 대화 데이터를 함께 섞어 학습해 이를 막는다(이번에는 하지 않음).
- LoRA 파일은 따로 저장되므로 LoRA를 끄면 최종 SFT 모델 그대로 돌아온다. 원래 모델을 망가뜨리지 않고 여러 LoRA를 바꿔 끼울 수 있다는 것이 LoRA의 장점이다.

## DPO: 상투 답 줄이기

**DPO(Direct Preference Optimization)**: 같은 질문에 "좋은 답"과 "나쁜 답" 쌍을 주고, 학습을 시작할 때의 모델(참조 모델, 얼려 둠)과 비교해 좋은 답의 확률은 올리고 나쁜 답의 확률은 내리도록 학습한다. 원본 `train_dpo.py`의 손실을 그대로 썼다.

- 데이터: SFT 학습 질문 9,749개에 최종 SFT 모델로 greedy 생성(약 15분). 9,749개 답 중 3,091개(32%)가 20번 이상 나온 같은 답 38종이었다(1위 "그런 사람 만나지 마세요." 734번, 2위 "그런 사람 만나세요." 297번, 3위 "잘할 수 있을 거예요." 240번). 이 중 정답과 같은 8개를 빼고 **좋은 답 = 데이터의 정답, 나쁜 답 = 모델의 상투 답**인 3,083쌍을 만들었다. 대화 평가 데이터와 200문항은 쓰지 않았다.
- 설정: beta 0.1, lr 1e-6(원본 기본 4e-8은 원본의 큰 DPO 데이터 기준), 1 epoch(386 step), batch 8. 학습 약 1분. DPO loss 0.69(구분 못함) → 마지막 구간 0.04~0.18.

| 측정 (일반 대화) | 최종 SFT | DPO 후 |
|---|---|---|
| 200문항: "그런 사람 만나지 마세요." / "그런 사람 만나세요." | 21 / 6 | **0 / 0** |
| 200문항: 서로 다른 답 | 152 | 112 |
| 200문항: 3번 이상 나온 같은 답이 차지한 문항 | 51 | 92 |
| 200문항: 상한에서 잘린 답 | 3 | 7 |
| 200문항: 답 하나의 평균 새 토큰 수 | 10.6 | 16.0 |
| 대화 평가 2,001쌍 답 본문 BPB | 1.0958 | 1.1664 (Δ +0.0705 [+0.0641, +0.0774]) |
| 대화 평가 답 끝 EOS 손실 (답 하나당 평균) | 0.11 nats | **2.74 nats** (Δ +3.79비트 [+3.62, +3.96]) |

DPO 후 200문항에서 가장 많은 답: "자신을 더 사랑해주세요."(22번), "자신의 마음을 정리하는 데는 시간이 걸릴 거예요."(19번), "자신에게 물어보는 것도 좋을 것 같아요."(16번).

README 대화 예시 10문항의 답 (같은 greedy 설정):

| 질문 | 최종 SFT | DPO 후 |
|---|---|---|
| 진짜 이제 한계야 | 진짜로 끝낼 수 있을 거예요. | 진짜로 끝낼 수 있을 거예요. |
| 양심이 콕콕 | 아무래도 괜찮아요. | 자신의 마음을 정리하는 시간입니다. |
| 나를 좋아한다는 사람한테 호감이 생길까요? | 그 사람도 좋아할 거예요. | 자신을 사랑하고 사랑한다는 사람에 따라 다르겠지만 사랑한다는 사람에 따라 다르겠지만 … [상한에서 잘림] |
| 결국 또 꿈꿨네. | 꿈이 필요하죠. | 자신의 꿈을 꿨나요. |
| 이제 헤어진지 1주일됐어 | 그런 날이 있나봐요. | 생각보다 많은 시간이 흘렀네요. |
| 오늘 비가 와서 그런지 기분이 좀 가라앉아 | 그런 날이 있나봐요. | 진정한 사랑이네요. |
| 대한민국의 수도는 어디야? | 수도권 매립지에서는 매립지를 찾아보세요. | 지금은 다 잊고 살지만 잊혀지지 않는 시간입니다. |
| 세종대왕은 어떤 일을 했어? | 그럴 때가 있죠. | 인맥이 넓었나봐요. 인맥이 넓었나봐요. |
| 다음 문장을 영어로 번역해 줘: 나는 학생이다 | 그게 내가 원하는 것일까요. | 공통점 (줄바꿈) 공통점에는 영어가 적혀있지 않아도 되는 것 같아요. |
| 123 더하기 456은 얼마야? | 그게 맞을 거예요. | 인공지능이 아닐까요? |

- **겨냥한 상투 답은 사라졌다**(21 → 0). 하지만 모델은 "자신 …"으로 시작하는 **다른 상투 답**을 새로 반복했고, 서로 다른 답은 오히려 줄었다(152 → 112). "이 답은 나쁘다"만 배웠지 "어떤 답이 좋은지"를 충분히 배우지는 못한 것으로 보인다.
- **답이 길어지고 끝내기를 어려워했다.** 평균 답 길이가 10.6 → 16.0토큰으로 늘고, 반복 루프로 잘린 답도 3 → 7개로 늘었다. 대화 평가 2,001쌍에서 정답 답변이 끝나는 위치에 EOS를 줄 확률은 평균 0.963 → 0.211로 떨어졌고, 0.5 미만인 답이 1.7% → 83.7%가 됐다.
- 원인(추정): 나쁜 답(상투 답)이 모두 짧고 곧바로 `<|im_end|>`로 끝나는 문장이라, "나쁜 답의 확률을 내리는" 과정에서 짧은 답 뒤에 곧바로 끝내는 것 자체의 확률도 함께 내려간 것으로 보인다. 좋은 답과 나쁜 답의 길이·형태가 체계적으로 다르면 DPO가 내용이 아니라 그 차이를 배울 수 있다.
- EOS를 뺀 답 본문 BPB도 나빠졌다(+0.0705). 끝내는 위치뿐 아니라 정답 답변의 본문 자체도 덜 예측하게 됐다는 뜻이다. DPO는 정답의 확률을 직접 올리는 학습이 아니라, 참조 모델에 비해 좋은 답과 나쁜 답의 확률 차이를 벌리는 학습이라 이런 일이 생길 수 있다.

## 배운 점

- **LoRA**: 전체의 0.55%(0.8MB)만 학습해도 모델의 행동을 크게 바꿀 수 있다. 대신 학습률에 민감했다(1e-4는 효과 없음, 1e-3은 과하게 바뀜). 좁은 데이터만으로 학습하면 그 행동이 모든 질문으로 번진다. 끄면 원래 모델로 돌아온다.
- **DPO**: 겨냥한 나쁜 답은 정확히 없앴지만, 새 상투 답과 긴 반복 답이라는 부작용이 생겼다. 나쁜 답만 골라서 주면 모델이 "다른 방식으로 비슷하게" 피해 가고, 좋은·나쁜 답의 길이 같은 표면적 차이까지 배운다.
- 두 기법 모두 "목표 지표는 좋아졌는데 다른 곳이 나빠지는" 모습을 보였다. 목표 지표 하나만 재면 이런 부작용을 놓치므로, 일반 대화 집계·BPB 같은 부작용 측정을 함께 정해 둔 것이 도움이 됐다.

## 한계

- 설정마다 학습 1회(seed 42). LoRA는 lr 두 개, DPO는 설정 하나만 해 봤다. 일반 데이터를 섞은 LoRA, 다른 beta·lr의 DPO는 하지 않았다.
- 대화 품질은 자동 집계와 BPB로만 봤다(블라인드 평가 없음).
- 측정에 쓴 07번 200문항과 데모 10문항은 08번 문서에서 이미 본 질문이다(학습에는 쓰지 않음).
- LoRA 결과 중 BPB는 합친(fp16 반올림) 가중치로 쟀다. 켠 모델과의 logit 최대 차이는 2.7e-3이다.
- 가중치는 공개하지 않는다.
